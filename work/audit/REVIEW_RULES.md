# 照合の決まり(全項目の原典照合・読むだけ)

これはクリニックに納品する Web マニュアルです。**正確さが最優先**です。あなたの仕事は、担当の Web 項目を元の PDF と一文ずつ照らし合わせ、**違いを報告すること**です。ファイルは一切直さないでください(報告ファイルを書くだけ)。

## 材料
- Web の中身: `python3 work/audit/topic.py <項目id>` で表示(作業フォルダ /Users/teradatakeshi/claude/やまうちクリニック操作ガイド)。担当の項目一覧は data/topics_<記号>.json
- PDF の文字: `python3 work/audit/pdfpage.py <ページ> [<ページ>...] --noimg`(PDF のリンク先 URL も [LINK] で出ます)
- PDF の見た目: `--noimg` を外すと /private/tmp/claude-501/-Users-teradatakeshi-claude/0ed2efdc-3b67-4aa3-9f7a-00796a7cb116/scratchpad/pdf/pNNN.png に保存されるので Read で見る。表・画面写真の中の文字・吹き出しを確かめる時に使う
- Web の手順に付いた画面写真は site/img/pNNN_K.webp(Read で見られる)

## 報告するもの(これだけ)
1. **意味の変化**: 必須→任意(「〜してください」→「〜してよい」)、禁止・条件・順番・対象の変化
2. **抜け**: 条件・対象者・数値・日付・期限・ボタン名・注意書き(※)・例外・参照先(文書名・版・ページ)・表の備考
3. **原典にない追加**: PDF に書かれていない説明・推測・一般化・別称・院内ルール(要約や言い換えで意味が同じものは除く)
4. **取り違え**: 数値・ボタン名・画面名・用語・章番号(manualTitle)・ページ番号の誤り
5. **画像の付け違い**: 手順の文と付いている画面写真が明らかに合わない

**報告しないもの**: 意味が同じ言い換え・要約・語尾の違い・「クリック」→「押す」など。迷ったら報告し、「軽微」と書く。

## 報告ファイル
`work/audit/review_<記号>.md` に、見つかった違いを1件ずつ次の形で書く。違いがない項目は最後に id だけ列記する。

```
### <項目id> / PDF <ページ>
- 種類: 意味の変化 / 抜け / 原典にない追加 / 取り違え / 画像の付け違い
- 重さ: 重大(操作を誤る・算定や請求を誤る) / 中 / 軽微
- PDF原文: 「……」(そのまま引用)
- Web現在: 「……」(そのまま引用。場所: 手順の何番・注意・要約など)
- 直し方の案: 「……」(PDF に沿った具体的な文)
```

最後に「確認した項目数・違いがあった項目数・違いなしの id 一覧」を書く。推測で埋めず、PDF で確かめたことだけを書くこと。
