# 手順データの作り方(全担当共通)

元資料: 電子カルテ「デジカル」操作マニュアル(705ページ)。やまうちクリニック(東京都世田谷区、内科・小児科、自費診療も多い、院内処方)の受付・看護・医師が、忙しい時にすぐ引けるガイドにする。

## 読むもの
- `work/pages/pNNN.json` … 1ページ分。items は上から読む順。`type:text` は文字、`type:img` は画面写真(`src` が画像のパス。赤枠つき)。
- 画像の中身を確かめたい時は `site/img/pNNN_K.jpg` を Read で見てよい(全部見る必要はない。迷った時だけ)。

## 書くもの
担当範囲を `data/topics_<担当記号>.json` に、次の形の配列で書く。1トピック = マニュアルの小見出し(①②…)1つが基本。長すぎる時は分け、短すぎる関連見出しはまとめてよい。

```json
[
  {
    "id": "b-uketsuke-torikeshi",
    "category": "uketsuke",
    "title": "受付を取り消す",
    "manualTitle": "III-1-② 受付取消",
    "pages": [49, 50],
    "summary": "間違えて受付した患者さんの受付を消します。",
    "keywords": ["受付取消", "受付キャンセル", "受付削除", "間違えて受付", "うけつけ とりけし"],
    "situations": ["間違えて別の患者さんを受付してしまった"],
    "parts": [
      {
        "heading": "",
        "steps": [
          { "text": "取り消したい患者さんの「ステータス」を押す", "imgs": ["img/p049_1.jpg"] },
          { "text": "一番下の「取消」を押す", "imgs": ["img/p049_2.jpg"] }
        ]
      },
      {
        "heading": "カルテを作った後のとき(先にカルテを削除)",
        "steps": [ { "text": "…", "imgs": ["img/p049_3.jpg"], "note": "補足があれば" } ]
      }
    ],
    "warnings": ["カルテを作った後は受付を取消できません。先にカルテを削除してください。"],
    "tips": ["削除したカルテも更新履歴から見られます。"],
    "related": ["b-karte-sakujo"]
  }
]
```

## 決まりごと
- **id**: 先頭に担当記号(例 `b-`)。英小文字とハイフン。
- **category**(この8つだけ): `login`(起動・ログイン・画面の見方・機器連携) / `uketsuke`(受付・患者登録・予約) / `hoken`(保険証・公費・労災・自賠責・自費の資格) / `shinsatsu`(カルテ・処置・処方・病名・検査・履歴) / `kaikei`(会計・返金・日計月計) / `receipt`(レセプト・月の請求) / `kanri`(設定・集計・ログ・利用者管理) / `santei`(算定の入力例・加算)
- **title**: 「〜する」の形の、やりたいこと。専門用語はマニュアルの言葉を残してよいが、なるべく普段の言葉で。20字以内。
- **summary**: 1文。何ができるか。
- **keywords**: 検索で引っかけたい言葉を8〜15個。マニュアルの用語、普段の言い方、言い換え、略さない語、ひらがな読み(難しい漢字のもの)、画面に出るボタン名。例: 返金 → 「払い戻し」「お金を返す」「保険証を後から持ってきた」。
- **situations**: 受付や診察中に実際に起きる困りごと・場面を1〜3個(「〜したい」「〜してしまった」「〜と言われた」)。無理に作らない。
- **steps.text**: 「(1)〜します」をそのまま写さず、短い命令形に言い換える(「〜を押す」「〜を選ぶ」「〜を入力する」)。情報は削らない。数字・ボタン名・画面名は正確に「」で囲む。
- **imgs**: その手順の直後にある画面写真を順番どおり全部つける。**担当範囲の画像は1枚も落とさない**(どの手順にも属さない画像は、近い手順に付ける)。
- **note**: 手順の補足(※書き)。
- **warnings**: 「できません」「注意」「必ず」など、間違えると困ること。短く。
- **tips**: 知っておくと便利なこと。
- **related**: 関連トピックの id(自分の担当内だけでよい。他担当の内容に触れる時は tips に言葉で書く)。
- 偽名・見本データ(テスト太郎など)はそのまま。
- 文字は全角/半角を自然に。絵文字は使わない。

## 最後に
`python3 work/check.py data/topics_<記号>.json <開始ページ> <終了ページ>` を実行し、エラー(画像の落ち・形の間違い)が0になるまで直す。
